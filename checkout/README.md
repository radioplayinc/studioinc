# Studio Sites — checkout / payment site for recording studios

The sales site for the recording-studio booking template. A studio owner
picks a package, chooses full payment or 50% deposit, optionally adds a care
plan, leaves their details, and pays through Jim. Adapted from the locked
Moovit Sites checkout (`~/workspace/moovit-sites-checkout/`), reskinned for
studios — same prices, same Jim links, same guarantee and timelines.

## Pricing (locked, same as Moovit Sites)

- Starter $2,499 (deposit $1,249) — live up to 7 days
- Pro $3,499 (deposit $1,749) — live up to 14 days, most studios pick this
- Premium $3,999 (deposit $1,999) — live up to 30 days
- Care plan $70 / $150 / $200 per month by package, first month free,
  manual monthly invoices (no recurring links)

Guarantee on the page: "We fix it until you're happy — and you don't pay
the final balance until you are."

## Flow

Loader ("View demo" links to the Amplitude Studios demo once
`CONFIG.demoUrl` is set) → packages → full vs 50% deposit → care plan →
studio details → review → Pay securely (Jim popup, new-tab fallback on
mobile; Jim blocks iframe framing) → confirmation with next steps + order
ref BQ-####.

## Files

- `index.html` — the app (single file, vanilla JS)
- `generate_assets.py` — regenerates icons + og card (STUDIO SITES wordmark)
- `manifest.webmanifest` — copy the pattern from the demo folder when
  deploying; icons and og-image are generated by the script above

## Before it goes live

- Set `CONFIG.demoUrl` in index.html to the public Amplitude demo link so
  the "View demo" button shows.
- The 6 Jim links in CONFIG.paymentLinks are the live Moovit Sites links
  (amount-based, reusable for studio sales at the same tiers). Verify they
  still return HTTP 200 before a big push.

## Deploy

Static site: GitHub repo → Cloudflare Pages (preset None, no build command,
output directory `/`).
